## 3. RFP 소개

MAKJI 자사몰에 금융•시장 데이터 기반 신규 기능을 기획•구현하는 AI PM 프로젝트입니다.

## 3-1. 프로젝트 요구사항

프로젝트 목적

기능 구현 주제 제시
금융 시장 데이터(주식•환율•금•날씨•SNS 트렌드 등)를 활용해, 자사 막지(MAKJI) 브랜드의 자사몰에 반영 가능한 구 매 전환 구조 관련 신규 기능을 기획하고 실제로 구현•검증하는 프로젝트입니다. 소비자가 매일 방문하고 즐길 수 있는 AI 기반 Food FinCommerce 기능을 구축하여, 데이터 기반 참여형(Gamification) 경험으로 자발적 재방문•구매전 환을 유도하고, Bread Market 검증 결과를 바탕으로 Bakery ETF•FX Bakery•Bread Index까지 단계적 확장 로드 맵을 확보하는 것을 목표로 합니다.

- 기능 예시: KOSPI‧KOSDAQ•환율•금•날씨•SNS 트렌드 데이터로 일일 할인•이벤트 자동 추천
- 구매 전환 구조: 플랫폼 이용 → 상품 관심 → 구매 전환 → 재방문으로 이어지는 고객 여정
- 예시: 금값 3% 하락 → 초코 제품 5% 할인
- 예시: 달러 하락 → 견과류 포함 제품군 할인
- 예시: 엔화 하락 → 말차 제품 할인
- 예시: 유로 하락 → 프랑스 버터 제품 할인

타겟 고객(사용자)

- MAKJI 소비자 - 데일리 소비재 특성상 ‘매일 방문’ 유도가 핵심 니즈
- 금융•시장 정보에 관심이 있고, 게이미피케이션(일일 미션•예측•리워드) 요소에 반응하는 소비자층
- 재방문율•구매전환율•객단가 등 KPI 에 민감하게 반응하는 브랜드 운영진(내부 사용자)도 간접 타겟

우수팀 선정 및 인센티브 구조

- 수강생은 RFP(기업 요구사항)에 맞춰 실제로 동작하는 프로토타입 형태의 MVP 산출물을 제작
- 우수팀으로 선정된 MVP 는 기업의 수요에 따라 자사몰에 실제로 연동되는 기회를 제공하며, 라이브 서비스 반영 및 광고 집행까지 이어질 예정
- 이후 재방문율.전환율 등 실제 운영 성과 지표를 우수팀에 공유
- 우수팀으로 선정되지 않더라도, RFP 기반 MVP 도출 경험 자체를 실무형 포트폴리오 산출물로 확보 가능

프로젝트 범위 및 산출물 (5 개 영역)

1. Bread Market은 실제 구현, (2)(3)(4)는 기획/설계 문서

| 영역 | 주요 내용 | 산출물 형태 |

| (3) FX Bakery (환 율 연계 프로모션) | 환율 변동과 연계한 국가별 원료•제품 프로모 션 자동 생성 예) 엔화 하락 → 말차 제품 할인 | 프로모션 시나리오 적용 조건, 대상 상품, 할인•쿠폰 정 책, 운영 절차 |
| (4) Bread Index (막지 브랜드 지수) | 판매량•재구매율•검색량•SNS 반응•고객만족 도를 지수화한 실시간 브랜드 인덱스 | 설계 문서 산출 기준, 가중치, 업데이트 주기, 시각화 방 식 |

- 반드시 기업과의 사전 협의 및 승인을 거쳐 콘텐츠를 최종 선정•적용하는 운영 구조로 설계

## 3-3. 구현 흐름

팀 서버에서 외부 API를 받아와 데이터 기반 기능 기획

1. 데이터 수집 - 팀 서버가 매일 외부 API(금융위•수출입은행•기상청•네이버)에서 시장 데이터를 가져옴
2. 로직 판단 - 그 데이터를 바탕으로 ‘오늘 뭘 할인할지’ 팀 서버가 자체적으로 계산 (기능 기획)
3. 자사몰 반영 - 카페24 API(Client ID/Secret)로 실제 자사몰 상품가•쿠폰을 업데이트
